# bilibili-cli v0.1.0

Date: 2026-08-17

首个正式版本提供完整的 Bilibili 终端工作流, 覆盖日常查询, 账户管理和媒体保存.

## Highlights

- 使用按领域组织的 CLI 命令查询视频, 用户, 搜索, 收藏和动态.
- 支持扫码与手机号短信登录, 并保存 Web 与 App 凭证.
- 下载视频, 音频和字幕, 自动处理 DASH 合并, 多分P选择和字幕匹配.
- 在服务器支持 Range 时并行下载媒体, 交互终端显示进度.
- 下载视频, 专栏, 番剧和用户的封面及可选头像.

## Features

- 视频: 查看详情, AI 总结, 评论, 相关推荐和分P信息.
- 搜索与发现: 提供综合搜索, 分类搜索, 热门视频和排行榜.
- 账户: 管理收藏, 关注, 历史, 稍后再看, 动态和互动操作.
- 输出: 支持交互表格, JSON 和 YAML 的稳定结果结构.
- 安全: 通过 `safety.read_only` 阻止账户写操作, 保留查询和下载能力.

## Bug Fixes

- 动态: 恢复个人动态列表的加载, 保留置顶动态过滤并兼容只读查询.
